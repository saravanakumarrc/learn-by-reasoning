# Phase 11: LLM Application Engineering

**Stage:** AI Solution Architect

## Why this phase exists here

The first phase where you actually build something with an LLM. Prompting and structured outputs are the 'Hello World' of AI application architecture.

## The question this phase should leave you able to answer

> Why would you ask the model to output JSON instead of just parsing its prose?

## Sections in this phase
- **[Prompt engineering](01-prompt-engineering/README.md)** — How you steer model behavior without retraining anything.
- **[Structured outputs](02-structured-outputs/README.md)** — How you make LLM output reliable enough for a program, not just a person, to consume.
- **[LLM patterns](03-llm-patterns/README.md)** — Composition patterns — chains, routers, critics — that every later RAG and agent pattern reuses under a different name.
