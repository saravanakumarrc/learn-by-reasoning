# Phase 10: AI / LLM Foundations

**Stage:** AI Solution Architect

## Why this phase exists here

The pivot point of the whole curriculum. Everything before this was 'traditional software architect'; everything after is 'AI Solution Architect.' Deliberately kept conceptual — this is not a research-level ML course.

## The question this phase should leave you able to answer

> Why would you pay more for a bigger model when a smaller one might do the job?

## Sections in this phase
- **[Understand](01-understand/README.md)** — What an LLM actually is and isn't — necessary before you can reason about any AI system built on top of one.
- **[Model selection](02-model-selection/README.md)** — The trade-offs — quality, latency, cost, privacy — an architect actually has to weigh, not a spec sheet to memorize.
- **[Model patterns](03-model-patterns/README.md)** — The landscape of model types and adaptation techniques (fine-tuning, quantization, distillation) you'll choose between.
