# Phase 19: LLMOps / AI Observability

**Stage:** AI Solution Architect

## Why this phase exists here

Extends Phase 2's observability foundations into AI-specific failure modes — hallucination, drift, agent loops — that ordinary logging, metrics, and traces don't catch by default.

## The question this phase should leave you able to answer

> Why doesn't your normal APM dashboard tell you the model just started hallucinating?

- **[Observability](01-observability/README.md)** — Traces and metrics extended to model calls, retrieval steps, and tool/agent steps.
- **[AI-specific monitoring](02-ai-specific-monitoring/README.md)** — The failure modes unique to AI systems, that traditional monitoring was never built to detect.
