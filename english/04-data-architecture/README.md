# Phase 4: Data Architecture

**Stage:** Senior Developer

## Why this phase exists here

Comes right after distributed systems because consistency, replication, and partitioning problems show up concretely in databases first, before they show up in application logic.

## The question this phase should leave you able to answer

> Why would you denormalize data you just spent effort normalizing?

## Sections in this phase
- **[Databases](01-databases/README.md)** — The mechanics of storing and querying data reliably — the base every other data topic in the curriculum sits on top of.
- **[Data architecture](02-data-architecture/README.md)** — How data moves and scales at organization scale (pipelines, lakes, governance), not just inside one database.
- **[AI-specific data](03-ai-specific-data/README.md)** — A deliberate early preview of embeddings and vector search. Flag: this is a forward reference — it will make much more sense once you've done Phase 10 (AI/LLM Foundations). Skim it now, come back to go deep after Phase 12 (RAG).
