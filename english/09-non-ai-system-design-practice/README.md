# Phase 9: Non-AI System Design Practice

**Stage:** Solution Architect

## Why this phase exists here

A deliberate checkpoint before AI enters the picture at all: design traditional systems end-to-end using everything from Phases 1-8. This is the Solution Architect capstone that confirms you're ready, before AI Solution Architect begins.

## The question this phase should leave you able to answer

> Could you defend every choice in this system on a whiteboard, without any AI involved?

## Sections in this phase
- **[System design practice](01-system-design-practice/README.md)** — A repeatable method — requirements, estimation, HLD, trade-off analysis — you'll reuse almost unchanged for AI systems later (Phase 24).
- **[Practice systems](02-practice-systems/README.md)** — Concrete systems to run that method against: URL shortener, payment system, booking system, and others.
