# Phase 21: AI Reliability

**Stage:** AI Solution Architect

## Why this phase exists here

Extends Phase 7's reliability engineering into a fundamentally different assumption: AI systems are probabilistic, not deterministic, so 'retry until it works' isn't automatically valid the way it is for a failed network call.

## The question this phase should leave you able to answer

> Why can't you just retry a hallucinated answer the same way you'd retry a failed API call?
