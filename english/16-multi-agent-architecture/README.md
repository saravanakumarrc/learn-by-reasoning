# Phase 16: Multi-Agent Architecture

**Stage:** AI Solution Architect

## Why this phase exists here

Once single agents are understood, the natural next question is when to split work across several. This phase is explicitly framed around justifying that decision, not assuming it.

## The question this phase should leave you able to answer

> Do I actually need multiple agents, or is one agent with more tools enough?

## Sections in this phase
- **[Learn](01-learn/README.md)** — Specialization, coordination topologies (supervisor, peer-to-peer), and the identity/permission questions that multiple agents introduce that a single agent never had.
