# Phase 6: Security Architecture

**Stage:** Technical Lead

## Why this phase exists here

Sits right after infrastructure because most security controls (IAM, network segmentation, secrets) attach directly to the infrastructure primitives just learned. AI security closes the phase as a necessary early preview.

## The question this phase should leave you able to answer

> Why isn't authentication enough — why do we also need authorization?
