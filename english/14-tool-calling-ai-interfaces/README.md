# Phase 14: Tool Calling & AI Interfaces

**Stage:** AI Solution Architect

## Why this phase exists here

The moment an LLM stops just talking and starts doing. This is the architectural transition from 'chatbot' to 'agent,' and MCP is the emerging standard for that boundary.

## The question this phase should leave you able to answer

> Why does a tool call need permission checks that the model's own reasoning doesn't?

## Sections in this phase
- **[Learn](01-learn/README.md)** — How function calling actually works end to end, including failure, retries, and human approval gates.
- **[MCP](02-mcp/README.md)** — The protocol standardizing how models discover and call tools across systems, instead of every integration being bespoke.
