# Phase 18: AI Evaluation

**Stage:** AI Solution Architect

## Why this phase exists here

Placed after orchestration on purpose — you now have full AI systems to evaluate (RAG, agents, multi-agent, orchestrated), not just isolated prompts. This is the formal evaluation layer; ideally you were already informally asking 'how would I evaluate this?' back in Phases 12 and 15.

## The question this phase should leave you able to answer

> How do you know this AI system works, when the same input might not even produce the same output twice?

## Sections in this phase
- **[Evaluation](01-evaluation/README.md)** — The methodology — offline vs online evaluation, golden datasets, LLM-as-judge.
- **[RAG metrics](02-rag-metrics/README.md)** — Precision, recall, faithfulness — the numbers specific to retrieval quality.
- **[Agent metrics](03-agent-metrics/README.md)** — Task success, tool-selection accuracy — the numbers specific to agent behavior.
