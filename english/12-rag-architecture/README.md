# Phase 12: RAG Architecture

**Stage:** AI Solution Architect

## Why this phase exists here

The first major AI architecture discipline: grounding a model in your own data. Sits right after LLM App Engineering and before Memory, Tools, and Agents, since retrieval is a prerequisite skill for all three.

## The question this phase should leave you able to answer

> Why does adding more retrieved context sometimes make answers worse?

## Sections in this phase
- **[Learn](01-learn/README.md)** — The full retrieval pipeline, ingestion through reranking.
- **[RAG architecture](02-rag-architecture/README.md)** — Naive vs advanced vs agentic RAG — knowing which one a given problem actually needs, not defaulting to the most complex one.
- **[RAG failure modes](03-rag-failure-modes/README.md)** — Where RAG systems actually break in practice, so you design against real failure instead of the demo-day happy path.
