# Phase 13: AI Memory

**Stage:** AI Solution Architect

## Why this phase exists here

A subtle discipline often confused with RAG or plain chat history. This phase exists specifically to draw that line before you build anything that needs to remember things across sessions.

## The question this phase should leave you able to answer

> Why is 'remembering everything' not obviously the right design?

## Sections in this phase
- **[Memory types](01-memory-types/README.md)** — The taxonomy — episodic, semantic, working, procedural — that clarifies what you're actually building before you build it.
- **[Architecture](02-architecture/README.md)** — The hard operational questions: what to forget, when to update, how to prevent memory poisoning.
