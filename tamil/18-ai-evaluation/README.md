# Phase 18: AI Evaluation

**Stage:** AI Solution Architect

## இந்த phase ஏன் இங்க இருக்கு

Orchestration-க்கு அப்புறம் intentional-ஆ வைச்சிருக்கோம் — இப்போ isolated prompts இல்லாம, full AI systems (RAG, agents, multi-agent, orchestrated) evaluate பண்ண உங்க கிட்ட இருக்கு. இது formal evaluation layer; Phase 12, 15-லயே 'இதை எப்படி evaluate பண்றது'ன்னு informal-ஆ கேட்டுட்டு இருந்திருக்கணும்.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> Same input-க்கு same output வராத போது, இந்த AI system வேலை செய்யுதுன்னு எப்படி தெரிஞ்சுக்குவீங்க?

## இந்த phase-ல இருக்கிற sections
- **[Evaluation](01-evaluation/README.md)** — Offline vs online evaluation, golden datasets, LLM-as-judge மாதிரி methodology.
- **[RAG metrics](02-rag-metrics/README.md)** — Precision, recall, faithfulness — retrieval quality-க்கே specific-ஆ இருக்கிற numbers.
- **[Agent metrics](03-agent-metrics/README.md)** — Task success, tool-selection accuracy — agent behavior-க்கே specific-ஆ இருக்கிற numbers.
