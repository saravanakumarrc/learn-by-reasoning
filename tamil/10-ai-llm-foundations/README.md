# Phase 10: AI / LLM Foundations

**Stage:** AI Solution Architect

## இந்த phase ஏன் இங்க இருக்கு

இந்த curriculum முழுசுக்கும் pivot point இது. இதுக்கு முன்னாடி எல்லாம் 'traditional software architect', இதுக்கு அப்புறம் எல்லாம் 'AI Solution Architect'. Intentional-ஆவே conceptual-ஆவே வைச்சிருக்கோம் — இது ஒரு research-level ML course இல்ல.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> ஒரு small model job பண்ணும்னா, ஏன் ஒரு bigger model-க்கு அதிகமா pay பண்றீங்க?

## இந்த phase-ல இருக்கிற sections
- **[Understand](01-understand/README.md)** — LLM என்னன்னு, என்ன இல்லனு actually — இதுல build ஆகுற எந்த AI system-ஐயும் reason பண்றதுக்கு முன்னாடி இது தேவை.
- **[Model selection](02-model-selection/README.md)** — Quality, latency, cost, privacy மாதிரி trade-offs — ஒரு architect actually weigh பண்ணணும், spec sheet memorize பண்ண இல்ல.
- **[Model patterns](03-model-patterns/README.md)** — Model types, adaptation techniques (fine-tuning, quantization, distillation) landscape — இதுல எதை choose பண்றீங்கன்னு.
