# Phase 9: Non-AI System Design Practice

**Stage:** Solution Architect

## இந்த phase ஏன் இங்க இருக்கு

AI entirely picture-க்குள்ள வர்றதுக்கு முன்னாடி ஒரு intentional checkpoint — Phase 1-8-ல கத்துக்கிட்டதை use பண்ணி traditional systems-ஐ end-to-end design பண்ணுங்க. AI Solution Architect ஆரம்பிக்கிறதுக்கு முன்னாடி நீங்க ready-ஆனீங்களான்னு confirm பண்ற Solution Architect capstone இது.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> AI involve ஆகாம, இந்த system-ல ஒவ்வொரு choice-ஐயும் ஒரு whiteboard-ல நீங்க defend பண்ண முடியுமா?

## இந்த phase-ல இருக்கிற sections
- **[System design practice](01-system-design-practice/README.md)** — Requirements, estimation, HLD, trade-off analysis — ஒரு repeatable method, later AI systems-க்கும் (Phase 24) almost அதே மாதிரி reuse பண்ணுவீங்க.
- **[Practice systems](02-practice-systems/README.md)** — அந்த method-ஐ run பண்ண concrete systems: URL shortener, payment system, booking system, மேலும் இதர.
