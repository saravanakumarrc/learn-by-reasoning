# Phase 4: Data Architecture

**Stage:** Senior Developer

## இந்த phase ஏன் இங்க இருக்கு

Distributed systems-க்கு உடனே அப்புறம் வைச்சிருக்கோம், ஏன்னா consistency, replication, partitioning problems முதலில் concrete-ஆ தெரியுது databases-ல தான், application logic-ல இல்ல.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> Normalize பண்ண effort போட்ட data-ஐ, ஏன் திரும்ப denormalize பண்றீங்க?

## இந்த phase-ல இருக்கிற sections
- **[Databases](01-databases/README.md)** — Data-ஐ reliable-ஆ store பண்றது, query பண்றது — இது curriculum-ல இருக்கிற வேற எல்லா data topic-க்கும் base.
- **[Data architecture](02-data-architecture/README.md)** — Organization scale-ல data எப்படி move ஆகுது, scale ஆகுது (pipelines, lakes, governance) — ஒரு database-க்குள்ள மட்டும் இல்ல.
- **[AI-specific data](03-ai-specific-data/README.md)** — Embeddings, vector search பத்தி ஒரு early preview, intentional-ஆவே இங்க வைச்சிருக்கோம். Flag: இது ஒரு forward reference — Phase 10 (AI/LLM Foundations) முடிச்ச பிறகுதான் இது full-ஆ புரியும். இப்போ ஒரு skim பண்ணிட்டு, Phase 12 (RAG) முடிச்ச பிறகு deep-ஆ திரும்ப வாங்க.
