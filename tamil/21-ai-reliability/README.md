# Phase 21: AI Reliability

**Stage:** AI Solution Architect

## இந்த phase ஏன் இங்க இருக்கு

Phase 7-ல கத்துக்கிட்ட reliability engineering-ஐ ஒரு fundamentally different assumption-க்கு extend பண்றது இது: AI systems probabilistic, deterministic இல்ல, அதனால ஒரு failed network call retry பண்றது மாதிரி 'retry பண்ணா வேலை செய்யும்' automatic-ஆ valid இல்ல.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question
