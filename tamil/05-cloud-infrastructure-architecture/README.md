# Phase 5: Cloud & Infrastructure Architecture

**Stage:** Technical Lead

## இந்த phase ஏன் இங்க இருக்கு

என்ன build பண்றோம்னு தெரிஞ்ச பிறகு (Phase 1-4), அது எங்க run ஆகுதுன்னு தெரிஞ்சுக்கணும். Compute, networking, containers, Kubernetes — இதுதான் later phase எல்லாம், AI phase-கள் உட்பட, deploy ஆகுற substrate.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> இதை VM-ல run பண்றதுக்கு பதிலா, ஏன் containerize பண்றோம்?

## இந்த phase-ல இருக்கிற sections
- **[Cloud fundamentals](01-cloud-fundamentals/README.md)** — Compute, storage, networking, IAM மாதிரி primitives — எந்த cloud provider ஆனாலும் இதுலேர்ந்துதான் build ஆகுது.
- **[Containers](02-containers/README.md)** — இதுக்கு மேல உள்ள almost எல்லா phase-உம் silent-ஆ assume பண்ற packaging unit.
- **[Kubernetes](03-kubernetes/README.md)** — 'My machine-ல run ஆகுது' stage-ஐ தாண்டின பிறகு, containers-ஐ orchestrate பண்ற dominant way.
- **[Platform engineering](04-platform-engineering/README.md)** — Manual deploy scale ஆகாம போன பிறகு, teams deployment-ஐ எப்படி industrialize பண்றாங்க — GitOps, IaC.
