# Phase 11: LLM Application Engineering

**Stage:** AI Solution Architect

## இந்த phase ஏன் இங்க இருக்கு

LLM வைச்சு actually எதையாவது build பண்ற முதல் phase இது. Prompting, structured outputs தான் AI application architecture-ஓட 'Hello World'.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> Model-ஓட prose-ஐ parse பண்றதுக்கு பதிலா, ஏன் JSON output கேட்கறீங்க?

## இந்த phase-ல இருக்கிற sections
- **[Prompt engineering](01-prompt-engineering/README.md)** — எதையும் retrain பண்ணாம, model behavior-ஐ எப்படி steer பண்றது.
- **[Structured outputs](02-structured-outputs/README.md)** — LLM output-ஐ ஒரு program consume பண்ண முடியுற அளவுக்கு reliable-ஆ ஆக்கறது எப்படி.
- **[LLM patterns](03-llm-patterns/README.md)** — Chains, routers, critics மாதிரி composition patterns — later RAG, agent pattern எல்லாம் இதையே வேற பேர்ல reuse பண்ணும்.
