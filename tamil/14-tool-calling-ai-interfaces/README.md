# Phase 14: Tool Calling & AI Interfaces

**Stage:** AI Solution Architect

## இந்த phase ஏன் இங்க இருக்கு

LLM வெறும் பேசாம, செய்ய ஆரம்பிக்குற moment இது. 'Chatbot'-லேர்ந்து 'agent'-க்கு போற architectural transition இது, அந்த boundary-க்கு MCP தான் emerging standard.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> Model-ஓட own reasoning-க்கு இல்லாத permission checks, ஏன் ஒரு tool call-க்கு தேவைப்படுது?

## இந்த phase-ல இருக்கிற sections
- **[Learn](01-learn/README.md)** — Function calling end to end எப்படி வேலை செய்யுது — failure, retries, human approval gates உட்பட.
- **[MCP](02-mcp/README.md)** — Systems எல்லாம் bespoke integration இல்லாம, models tools-ஐ எப்படி discover பண்ணி call பண்றதுன்னு standardize பண்ற protocol.
