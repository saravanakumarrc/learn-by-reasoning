# Phase 1: Architect's Developer Foundation

**Stage:** Developer

## இந்த phase ஏன் இங்க இருக்கு

இதற்கு மேல உள்ள எல்லா phase-உம் build ஆவது clean code, சரியான API contracts, application-level structure மேலதான். இதை skip பண்ணா, microservices அல்லது CQRS எதுக்கு தேவைப்படுதுன்னு புரியாம, ஒரு single codebase-ல அது என்ன problem solve பண்றதுன்னு தெரியாம, வெறும் pattern-matching பண்ண ஆரம்பிச்சுடுவீங்க.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> Modular monolith-லயே வேலை ஆகும்போது, ஏன் நமக்கு microservices தேவைப்பட்டது?

## இந்த phase-ல இருக்கிற sections
- **[1. Programming mastery](01-1-programming-mastery/README.md)** — Clean code, design patterns, concurrency, error handling மாதிரி craft-level vocabulary — later phase-ல எடுக்கிற ஒவ்வொரு design decision-உம் இது உங்களுக்கு already தெரியும்னு assume பண்ணும்.
- **[2. API engineering](02-2-api-engineering/README.md)** — REST endpoint-லேர்ந்து MCP tool வரைக்கும், later phase-ல இருக்கிற ஒவ்வொரு component-உம் இறுதியில இந்த contract layer மூலமா தான் communicate பண்ணும்.
- **[3. Application architecture](03-3-application-architecture/README.md)** — ஒரு deployable unit-ஐ எப்படி structure பண்றது. Curriculum-ல பின்னாடி வர microservices, event-driven systems, multi-agent systems போன்ற பெரிய pattern-கள் எல்லாம் இதே idea-வோட scaled-up version தான்.
