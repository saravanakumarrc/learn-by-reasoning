# Phase 7: Reliability Engineering & Cost Fundamentals

**Stage:** Technical Lead

## இந்த phase ஏன் இங்க இருக்கு

System build பண்ணி secure பண்ணின பிறகு, 'இது எவ்வளவு available ஆயிருக்கணும், அதுக்கு எவ்வளவு cost ஆகும்'-ன்னு ஒரு architect answer பண்ணணும். Original curriculum-ல இந்த phase இல்லவே இல்ல — non-functional requirements, cloud cost reasoning-க்கு home இல்லாம இருந்துச்சு.

## இந்த phase முடிச்ச பிறகு answer பண்ண முடிற question

> 99% availability-ஐ விட 99.9% ஏன் இவ்வளவு அதிகமா cost ஆகுது?

## இந்த phase-ல இருக்கிற sections
- **[Non-functional requirements](01-non-functional-requirements/README.md)** — SLA, SLO, SLI, RTO, RPO மாதிரி vocabulary — 'reliable-ஆ இருக்கணும்'-ஐ ஒரு specific, testable target ஆக்குது.
- **[Disaster recovery & high availability](02-disaster-recovery-high-availability/README.md)** — அந்த targets hit பண்ண என்ன build பண்றோம் — multi-region, failover, backup, restore.
- **[Cloud cost / FinOps](03-cloud-cost-finops/README.md)** — மேல உள்ள எல்லா decision-உம் real world-ல shape பண்ற economic constraint, வெறும் whiteboard exercise இல்ல.
